# Finance Tracker

A Python-based Finance Tracker developed as part of a Python Internship project.

## Features

- Add Income
- Add Expenses
- Categorize Transactions
- Command Line Interface (CLI)
- JSON-based Data Storage

## Technologies Used

- Python
- argparse
- Git & GitHub
